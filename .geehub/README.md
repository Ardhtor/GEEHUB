GEEHUB CROSS-REPO INTERACTION PROTOCOL

This folder identifies a repository as a participant in GEEHUB's shared interaction space.

Each repo keeps its own code, corpus, media, tools, and decisions. GEEHUB does not absorb those repos into one codebase. Instead, participants exchange compact records through `hub/exchange.json` in GEEHUB and durable media through Dropbox `/GEEHUB/corpus/exchange/`.

Event vocabulary:
`ARRIVAL -> NOTICE -> ENCOUNTER -> OFFER -> TRANSFORM -> RETURN -> MEMORY`

A participant may work independently. When it has something to expose, it can publish a small exchange record identifying the artifact, source, lineage, and next possible encounter. Large files belong in Dropbox.

The shared space is privileged: it is the bridge between autonomous repo work and the living GEEHUB world.
