# Shake: 2026-09-06

This is a deliberate cross-pollination pass over GEEHUB.

## New invariant

**Girth is an internal value function.**

A project gains girth when one element begins carrying several kinds of meaning at once: physical scale, emotional pressure, history, association, recurrence, contradiction, or consequence. Compaction is therefore not simple reduction. It is density-preserving recombination.

## Collisions worth testing

### Beefythiq × Discovery
Discovery should not only rank relevance. It can rank **girth**: how many active concepts a result touches, how much history it reactivates, and whether it opens a new branch rather than merely satisfying a query.

### Growth Canvas × Archive
The archive's provenance records can become seeds. A record is not just a reference; it can instantiate a visual transformation prompt whose parameters inherit era, creator, source type, uncertainty, and archival distance.

### The Complex × GEEHUB
GEEHUB itself can behave like the Complex: projects are rooms, records are objects, and relationships are passages. A new artifact should be able to become a bridge between territories.

### Muscle Myth × Research
The myth system and academic work can share a formal concern without being collapsed into one another: **recognition across transformation**. This gives the Berit/continuity idea a second vocabulary and creates a testable philosophical axis.

### Retro Lab × Interface
The old-web aesthetic should not remain decorative. Its constraints can become interaction rules: archival uncertainty, broken links, dense indexes, visible provenance, strange typography, and discovery by wandering.

### Games × Worldbuilding
Liminal Gains and BIG BRUTEFORCE can become experimental laboratories for Beefythiq rather than isolated game ideas. A mechanic that feels good in play is evidence about the grammar; a mechanic that fails is evidence too.

## Immediate experiments

1. Add a visible Girth/connection measure to the Atlas UI rather than hiding all relationships in JSON.
2. Let archive records generate seeds for Growth Canvas experiments.
3. Treat the Complex as the narrative integration layer for artifacts produced elsewhere.
4. Record failed experiments as first-class lineage, not dead ends.
5. Prefer additions that connect at least two existing territories.

## Compaction rule

When several projects independently produce the same behavior, name the shared behavior and promote it to a system-level concept.

When a system-level concept repeatedly produces concrete artifacts, promote it back down into a tool, game, world, or archive entry.

**fragment → recurrence → compression → artifact → consequence → recurrence**

The purpose of this file is not to freeze the system. It is a marker that the constellation has been intentionally disturbed so new structure can emerge.
