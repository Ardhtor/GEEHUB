# Adult Gay Visual Loop

An adult-only, swipe-first visual discovery space inside GEEHUB.

The interaction is deliberately simple: open, see, swipe. Each swipe advances to another adult visual artifact. The archive preserves provenance and learns from attention signals such as skips, pauses, saves, revisits, and returns.

The subject is adult gay visual culture, with a strong emphasis on muscular presence, bodies, charisma, style, environments, transformation, and continuity. The archive is a discovery surface rather than a conventional folder tree: the user should be able to move through it almost entirely by swiping.

## Core loop

`SEE -> SWIPE -> SURPRISE -> SWIPE -> RECOGNIZE -> SWIPE -> DISCOVER`

The system should not require the user to understand its metadata before receiving value. Metadata works underneath the experience: provenance, source, subject identity, visual motifs, tags, continuity links, and related artifacts.

## Recommendation behavior

Attention becomes the signal. Pauses, saves, revisits, back-swipes, and repeated visual motifs increase relatedness. Skips reduce it. The system should produce variation rather than simply repeating the same image class.

A familiar subject can return transformed by context. A visual motif can lead to a new person, a new environment, a new archive branch, or a generated study. Every encounter can become a doorway into another part of GEEHUB.

## Interface principle

One primary action: swipe.

Secondary actions should remain quiet: save, revisit, source, related, archive.

The screen should feel like a living feed rather than an administrative database. The archive does the organizational work in the background.

## GEEHUB relationship

This node connects the adult visual archive to `male-harem-virtual-space`, `discovery`, `media-tools`, `beefythiq`, and `the-complex`. Adult source material remains distinguishable from generated or transformed artifacts, with provenance preserved across the chain.

The intended feeling is continual discovery: there is always another image, another connection, another variation, another room behind the current one.
