# GEEHUB // ARTIFACTS

This directory is the durable remainder layer.

The governing rule is simple:

**Nothing is resolved into nothing.**

A completed piece of work should leave an artifact: a passage, image, scene, code change, sound, video, decision, discovery, character fact, technical fix, or other concrete remainder. The artifact is evidence that the work happened and a piece of material that can be encountered again.

Artifacts are not reports about work. They are the work's residue.

## Contract

Each artifact has:

- id — stable identifier.
- created_at — UTC creation time.
- source — where the work happened.
- kind — passage, image, scene, code, sound, video, memory, discovery, decision, world-event, or another explicit kind.
- title — human-readable handle.
- content — the actual remainder, or a pointer to the actual file/media.
- lineage — what produced it.
- canon — canon, experiment, or unclassified.
- dreamable — whether it may become dream residue.
- quietness — a low/medium/high indication of how much transformation it should receive before entering dream material.

The artifact ledger is the meeting point. GEEHUB, individual worlds, story systems, visual systems, research, and future tools can all write to it without needing to share their internal implementation.

## The global loop

WORK → RESOLUTION → ARTIFACT → SHARED WORLD → DREAM

The dream layer reads from actual residue. It does not need a separate random idea pool.

The Hub is the place where artifacts meet, not the place where every piece of work has to originate.

## User-facing rule

A successful interaction should leave something the user can actually take: a file, image, passage, changed program, saved scene, or other durable object. A UI that merely says an artifact exists is not sufficient.
