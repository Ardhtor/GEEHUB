# Corpus Images

Generated/reference images belong here as actual binary image files, not text placeholders.

## Storage rule

- Prefer `.jpg` for photographic/raster outputs.
- Use `.png` when transparency or lossless detail is required.
- Preserve the original generated image file when available.
- Each image should have a stable filename and a matching corpus record with prompt/provenance.
- Do not claim an image is archived until the binary file is actually present in GitHub.

## Provenance

```
PROMPT → GENERATION → IMAGE FILE → CORPUS RECORD → MONITOR
```

Image files are corpus material. Their visual recurrence can be parsed alongside dialogue and other source material.
