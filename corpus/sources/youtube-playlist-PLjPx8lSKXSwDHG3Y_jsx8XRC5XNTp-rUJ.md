# YouTube corpus source

Source: https://www.youtube.com/playlist?list=PLjPx8lSKXSwDHG3Y_jsx8XRC5XNTp-rUJ

Use this playlist as an external corpus stream for the continual monitor.

The monitor should treat the playlist as ordered material and examine:

- recurrence of small motifs across videos
- repeated words / phrases / sounds / images / titles
- spacing between recurrence events
- clusters formed between recurring events
- changes in recurrence over time or playlist order
- relationships between playlist material and existing corpus nodes
- whether the program's own interpretations begin recurring as new motifs

Do not impose a thematic taxonomy before parsing. Preserve the playlist's native order and provenance. A recurring small formation may become a delimiter only after recurrence is observed.

The playlist is an input source, not evidence for claims about the user's intent or authorship.
