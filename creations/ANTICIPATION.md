# ANTICIPATION

GEEHUB does not need to wait for a prompt before presenting a possible next move.

Anticipation is a production surface, not a prediction engine. It reads durable creations and world places already present in the corpus, then exposes a small set of actions: OPEN, ENTER, and BUILD.

The first result is allowed to become the current encounter. The remaining results stay adjacent. A queued artifact can therefore become a place; a place can become a chapter; a chapter can become a new artifact.

Anticipation never changes canon by itself. It proposes movement through the existing material.

The intended loop is:

encounter → selection → transformation → creation → archive → encounter

The interface should feel like a room that already contains the next object, rather than a task list asking what the user wants.
