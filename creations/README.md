# GEEHUB / CREATIONS

Creations is the product surface of the Hub.

It is not a feed and it is not a plan. It is the place where durable things appear: scenes, chapters, maps, characters, motion studies, images, sounds, experiments, and world-state artifacts.

Each creation should preserve:
- what it is
- where it came from
- what assets or places contributed to it
- what state it is in
- whether it belongs to canon or remains experimental

The existing artifact runtime can hold transient local traces. The Creations registry holds durable pointers to things that can be opened, revised, or used as inputs to another creation.

Canon stays separate from experiments.
