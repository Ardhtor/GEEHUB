# FORM / Athlete Lab

An interactive athlete profile built from a user-supplied gym portrait. The portrait acts as the surface for exploring five training regions: chest, shoulders, arms, core, and legs. Selecting a region changes the exercise suggestions; a small session control lets a visitor add working sets and see the weekly volume and rhythm respond.

## Run

Open `index.html` in a modern browser. The image is stored alongside the page. No build step or external dependency is required.

## Interaction

- Select a highlighted body region with a pointer, Enter, or Space.
- Adjust the working-set count and log a session.
- Watch the weekly volume, progress indicator, and training rhythm update.
- The session values live only in the current page session; refresh resets them.

## Origin and status

This is a prototype grown from the supplied portrait and the GEEHUB idea of turning imagery into a surface that can be explored and changed. Exercise suggestions are illustrative interface content, not a personalized coaching prescription. The athlete is identified only as Athlete 001; no biographical claims are intended.

**Status:** proposal for GEEHUB review. The next useful step would be to decide whether Athlete Lab belongs with Growth Canvas / Growth Tools, and whether its session state should persist or connect to a larger training system.
