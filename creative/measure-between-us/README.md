# The Measure Between Us

A GEEHUB story node about Chase and the fictional adaptations of Luke, Andrew Sim, and Tyler Ledbetter. Chase remains the point-of-view anchor; each character has a separate workspace and the ability to initiate consequential action.

The film treatment is being drafted in the user's local Codex outputs. This directory stages the story's collaboration structure inside GEEHUB so it can later be split into standalone GitHub repositories without losing its place in the Atlas.

## Fiction and attribution

Luke, Andrew Sim, and Tyler Ledbetter are adaptations built from the user's direction and limited public-facing cues. These files are fictional character work. They do not speak for the real people, claim their participation, or imply that their X handles are their GitHub accounts. No actual contributor account or permission has been assigned here.

## Character repository spaces

- [Chase Book](repos/chase-book/README.md) — choices, attention, memory, and the continuity record.
- [Luke Inside](repos/luke-inside/README.md) — bodily continuity, self-definition, and Luke's own next move.
- [Andrew Field](repos/andrew-field/README.md) — movement, shared play, and practical group decisions.
- [Tyler Measurement](repos/tyler-measurement/README.md) — instruments, uncertainty, and actions taken when measurement stops being enough.

Each space contains a first action seed. A character can originate an issue, make a decision that changes the scene, and propose a patch to the shared GEEHUB story. The user remains maintainer and decides what becomes shared canon.

## Real GitHub wiring

`Ardhtor/GEEHUB` is the canonical hub. The four workspaces above are local story seeds, not live GitHub repositories. The connected GitHub capability can read and edit existing repository content, but it has no operation for creating repositories or inviting collaborators. To wire real people in, use their exact GitHub usernames and obtain their agreement to the fictional collaboration. Do not infer GitHub identities from the supplied X handles.
