# Character repo lab

These are four GEEHUB-internal repository seeds. They are structured as independent project homes so each fictional character can originate work and send proposals back to the shared story. They are not four live GitHub repositories and do not represent accounts owned by the real people whose names inspired some characters.

## Collaboration loop

1. A character workspace records a question the character wants answered.
2. That character takes an action that changes the scene, a relationship state, a method, or an object.
3. The action is written as a proposal against the shared film treatment.
4. The user reviews and decides whether it belongs in GEEHUB's shared canon.

In an eventual real GitHub setup, each person would contribute only from their own verified account and after agreeing to the project. No account should be automated or simulated as if it belonged to a real person.
