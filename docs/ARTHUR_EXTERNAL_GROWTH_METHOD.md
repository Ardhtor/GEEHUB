# Arthur as an External Growth Metaphor

**Status:** production method, not fictional canon  
**Source inspiration:** Arthur and the Fingerlands  
**Boundary:** Arthur remains a fictional hero in the Fingerlands. This document records an external method inspired by the shape of his continuous growth; it does not make Arthur aware of, responsible for, or identical with the repository.

Arthur begins as one recognizable form and changes continuously. That offers a useful production metaphor: extend what is already present, preserve the line of inheritance, and let later structure emerge as a consequence of earlier structure. The metaphor applies to editing and building; it is not a fact about Arthur's life inside the Fingerlands.

When working in the repository, use the following external method:

1. **Enter the existing material.** Inspect relevant files, indexes, conventions, source records, and relationships before changing anything.
2. **Find the existing direction.** Infer the next useful extension from the actual structure and the user's expressed intent; do not impose an unrelated framework.
3. **Extend continuously.** Preserve established material and add the smallest coherent continuation that gives the idea room to develop.
4. **Give each change a proper home.** Put narrative, character records, assets, state, and executable behavior in their correct layers, and connect them through indexes and references.
5. **Preserve lineage.** Keep provenance, previous states, names, and relationships legible. A new baseline inherits its history; it does not pretend the earlier form never existed.
6. **Build for continuation.** Prefer reusable structures and clear records that make later work possible without requiring the same context to be reconstructed.
7. **Verify what changed.** Read back edited files and confirm the commit. Never describe an intention as a completed edit.

The metaphor is useful only while it remains subordinate to the subject. Arthur is not a mascot for every branch, every world, or every production decision. The Fingerlands keeps its own story, geography, and cast.
