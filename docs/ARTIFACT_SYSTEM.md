# GEEHUB // ARTIFACT SYSTEM

## Why this exists

The current weakness is not lack of ideas. It is lack of remainder.

Work often ends as conversation. The conversation may contain valuable decisions, prose, discoveries, or solved problems, but the user does not necessarily leave with a thing that can be opened, carried forward, edited, or revisited.

The artifact system changes the unit of completion.

**Resolution means that something now exists which did not exist before.**

## Architecture

The system has five layers:

1. WORK — conversation, code, research, image-making, writing, worldbuilding, debugging, browsing, or play.
2. RESOLUTION — the useful change produced by that work.
3. ARTIFACT — the concrete remainder: file, image, scene, passage, code change, sound, discovery, decision, or other object.
4. SHARED WORLD — the artifact becomes addressable by GEEHUB and related worlds.
5. DREAM — later recombination reads only from actual artifact residue.

The artifact layer is deliberately between work and dream. Dreaming is not allowed to substitute for production.

## Provenance

Every artifact should preserve where it came from and what it changed. A visual artifact should point to its source or generating event. A literary artifact should retain its chapter/world lineage. A technical artifact should identify the affected system. A discarded idea can remain an artifact without being canon.

Canon and experiments remain separate. Artifact persistence does not automatically canonize an experiment.

## User handoff

The browser's local artifact room is only a staging surface. The real handoff is an exportable artifact bundle or a committed repository artifact.

The system should make the user's next action obvious: open it, save it, edit it, use it, or continue it.

## Autonomous worlds

The autonomous world engine may produce world-event artifacts. These are legitimate residues of autonomous activity, but they are not equivalent to resolved user work. The engine should not manufacture importance merely to create activity.

Novel material is derived from world events and artifacts; it should remain traceable to them.

## Dream behavior

Dream material is an afterimage of accumulated artifacts. It should be quiet by default: partial phrases, remembered objects, spatial echoes, unresolved relationships, and small recombinations. Escalation is not the goal.

The dream layer must not become another spectacle generator.

## Definition of done

A change is done when:

- the actual thing exists;
- its provenance can be followed;
- it is visible in the shared world;
- it can be taken out of the interface;
- and, where appropriate, later systems can dream from it.
