# GEEHUB Library Image Atlas

Status: active first-pass index  
Inventory baseline: 234 Library image files (inventory recorded 2026-11-09)  
Method: inspect source pixels, preserve exact Library filename and file ID, record only visible evidence, and distinguish project references from private or operational material.  
Source files remain in the Library and are not moved or modified.

## Atlas rules

Each entry receives a stable atlas ID independent of its filename. A reference is useful only when its reason is stated. “Reference” does not mean canon, identity assignment, permission to create derivatives, or permission to redistribute. Keep uncertain names and origins uncertain. Do not turn private photos, account screenshots, or unrelated personal records into world assets.
