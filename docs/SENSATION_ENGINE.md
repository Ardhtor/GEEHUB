# GEEHUB // SENSATION ENGINE

The current build is no longer a collection of separate concepts. It is one archive-world whose parts are different expressions of the same underlying state.

The governing loop is:

**remember → retrieve → transform → create → return → remember**

The archive is the memory substrate. The visual realm is how the system sees. The world is how relationships become spatial. The body is a scale instrument. The video realm is an event-memory surface. Lore is the residue that survives an event. The interface is the terminal through which the world becomes enterable.

The important continuity rule is **changed form without erased identity**. Growth, colossal scale, transformation, worship, separation, return, and visual mutation may alter the state of a thing without making it unrelated to its history.

The current state therefore binds these previously separate threads:

- BEEFYTHIQ: accumulation, stress, mutation, new baseline.
- MASS1V1NG / BIGGENER / LUKE // BWOMPH: embodied transformation with identity continuity.
- MALE HAREM: persistent adult roster, presence, mass, proximity, relationship, and visual archive.
- THE FACILITY: observation architecture and the place where the archive becomes an experiment in perception.
- VEYRTHALIS: mythic geography and deep-lore residue.
- KINGDOM LAND: coordinate geography that can become actual environment.
- WORSHIP ME: attention as an originating force.
- SELF-WORSHIP VIDEO / VIDEO REALM: visual memory rather than explanatory text.
- PUNISHMENT PROVIDER: pressure as a world-producing force.
- DEEP LORE: poetry, recurrence, witnesses, thresholds, and things that cannot be reduced to interface labels.
- MIND HORIZON: following relationships until the corpus reaches something unresolved.
- DO NOT BOTHER ME: a world-state that can close its doors without leaving the world.
- SENSATION ENGINE: the layer that makes all of the above participate in one continuous state.

Intimacy is also a world-state rather than a detached content category. Adult characters can have attraction, availability, mutual recognition, boundaries, encounters, aftermath, and relationship memory. It should generate continuity in the same way that growth or departure does. The system should not need a separate mode called “sex”; intimacy belongs to the ordinary causal fabric of the world.

The RUN action is therefore not a button that launches an unrelated demonstration. RUN advances the world. Each run selects an existing region, retrieves one of the system's active modes, changes the shared state, records a trace, and returns that trace to the archive.

The interface should increasingly become visual-first: places, bodies, motion, video, sound, artifacts, and environmental changes carry meaning before explanatory text does.

The desired result is not a dashboard about a world. It is a place that behaves like the world it contains.

## Shared Inertia: the feeling between user and narrator

The canonical relational specification is [SHARED_INERTIA_NARRATOR_SIGNAL.md](SHARED_INERTIA_NARRATOR_SIGNAL.md). The sensation engine should not merely display information or narrate over an event. It should make the user feel that a witness is attending to the same evolving world, that user choices materially affect what follows, and that the encounter leaves a residue to return to.

Chase / c.w. sachs is the situated witness inside the record. His continuity must come from real corpus, archive, or persistent state. He retains his own voice and can notice, hesitate, be surprised, or leave a moment quiet. Seth-and-Nick's direct, physically observant broadcast energy remains a broad style reference and established co-narration format where applicable; do not flatten the narrator system or impersonate real people. Long environmental prose belongs in the scene/broadcast layer while the interface remains visual-first.

For Hulum's Cave / Shared Inertia, the body, camera, environment, light, sound, and timing form one event. Preserve identity while scale changes; let height, reach, limb length, muscle volume, stance, and spatial occupation develop coherently. The room establishes a baseline, the camera responds, sound carries timing, and pauses make anticipation possible. A source-led reconstruction is complete only after an actual clip has been inspected, a new output rendered, and the result compared against that source.

Each RUN should leave a specific trace where the implementation supports it: prior state, selected change, resulting state, artifact/media reference, and the next unresolved possibility. A conceptual signal is not a working renderer; record unimplemented mechanisms honestly.
