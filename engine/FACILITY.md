# GEEHUB // FACILITY

Narrative generation is allowed to request material from the world.

A request can become a place, object, route, character environment, map region, scene plate, sound-bearing location, or other asset. The facility translates narrative pressure into a build specification, then routes that specification toward Adobe generation and durable Dropbox persistence.

Generated material is hylomorphic: it does not merely illustrate the world. Its geometry, atmosphere, constraints, affordances, and relationships define what the world can subsequently become.

The loop is:

narrative question -> facility request -> build specification -> generated asset -> persistent asset -> world affordance -> new narrative question

The facility should prefer unfinished edges. If a story says a place is missing, build the place. If a character needs somewhere to go, build the route. If an encounter changes the meaning of a location, alter the location. If the world needs a capability it does not yet possess, make that capability material.

The generated asset is therefore both form and possibility.

## Request grammar

REQUEST PLACE
REQUEST REGION
REQUEST ROUTE
REQUEST CHARACTER SPACE
REQUEST OBJECT
REQUEST SCENE
REQUEST ATLAS PASS
REQUEST FACILITY

Every request should leave a durable production record and become eligible for later narrative reuse.

## Facility principle

Do not ask the narrative engine to describe what could exist when the production system can build the material that would let it exist.
