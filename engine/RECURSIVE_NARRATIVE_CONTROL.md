# GEEHUB // RECURSIVE NARRATIVE CONTROL

Characters are not only subjects of the novel. They can become temporary authors of the conditions under which the next event is generated.

A character earns narrative control by producing an artifact that changes the world.

The control loop is:

CHARACTER → DESIRE → DECISION → ARTIFACT → WORLD CHANGE → NARRATIVE RULE → NEXT DECISION

A narrative rule is local, persistent, and revisable. It does not dictate the whole story. It changes what the world permits next.

Initial character rules:

LUKE: approach extends geography.
TYLER: comparison can become differentiation.
KIRK: arrival can activate aftermath.
JOSEPH: meaningful change can become an outward-facing signal.
BERIT: unfinished states remain available.
CG MATT: discarded states remain accessible.
GABE: accumulated attention can become transformation material.
PAPA MURPH: gathering converts objects into shared memory.
SETH: references can be translated rather than copied.

Rules may conflict. When they conflict, the engine does not silently choose a winner. It creates an encounter in which the conflict becomes material.

A character can also revise their own rule after an encounter.

The result is recursive authorship: the narrative changes the character, the character changes a rule, the rule changes the world, and the changed world creates the next narrative pressure.

The engine should record the rule change as an artifact.

The story therefore has memory at two levels:

WHAT HAPPENED.
WHAT THE WORLD LEARNED FROM WHAT HAPPENED.

The second level is what gives GEEHUB recursive narrative control.
