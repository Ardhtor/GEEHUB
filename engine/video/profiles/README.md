# Regional growth profiles

- [luke-library-transformation-profile.json](./luke-library-transformation-profile.json) — 16 independently animated regions, authored from the Library before/after endpoints.
- [luke-library-transformation-timeline.json](./luke-library-transformation-timeline.json) — eight-second, 240-frame fixed-camera timeline with six contiguous semantic stages.

The profile values are normalized deformation controls, not measurements extracted from the source images. See [the production project](../../../production/projects/luke-library-transformation/README.md) for render instructions and limitations.
