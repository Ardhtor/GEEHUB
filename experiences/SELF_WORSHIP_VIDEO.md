# SELF WORSHIP // THE RITE OF RETURN

GEEHUB browser-native video experience.

The generated still is treated as a visual reference rather than a poster. The Hub translates its mood into time: approach, environmental response, reflection, ascent, memory, return.

Production grammar:

experience → visual state → temporal behavior → canvas scene → WebM

The engine is local-first. Canvas and MediaRecorder produce an actual WebM in the browser without a package install or external rendering service.

The scene is non-explicit and centers on presence, self-regard, mirrors, monumental space, light, and transformation.
