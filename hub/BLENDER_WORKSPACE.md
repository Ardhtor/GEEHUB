# Blender Workspace

The Blender node is the 3D production arm of GEEHUB.

## Purpose

Use this workspace for:

- character and proportion studies
- sculpt and topology experiments
- pose and silhouette exploration
- scene and lighting studies
- reference-driven modeling
- visual experiments derived from GEEHUB systems
- render-ready presentation scenes

## Connections

`BEEFYTHIQ` supplies transformation rules and escalation logic.

`Growth Canvas` supplies seeds, rules, latency, anomalies, and visual feedback.

`The Complex` supplies continuity, locations, artifacts, and canon.

`Muscle Myth` supplies characters, gods, symbols, and mythic visual motifs.

`BodyLounger Research Archive` supplies historical visual references and provenance links.

## Connector status

The user has indicated that a Blender connector/stand workspace exists on the same profile. Its concrete repository or connector identifier is not currently exposed through the available GitHub search surface, so this file acts as the stable integration point until that identifier is available.

## Operating principle

Do not treat a render as the end product. A useful Blender artifact should feed something back into the constellation: a reusable asset, a scene, a proportion rule, a visual grammar, a canon entry, or a new experiment.
