# GEEHUB / CORE GESTURE

## ONE PUTS HIS HEAD ON ANOTHER

This is the smallest complete event in the Hub.

One person places his head on another person.
The second person receives the weight.
Neither person has to become different for the event to matter.

The Hub treats this as a foundational relation:

HEAD → SHOULDER
WEIGHT → RECEIVED
DISTANCE → COLLAPSED
ATTENTION → SHARED
TIME → HELD
MEMORY → CREATED

It is not a metaphor layered onto the experience. It is a world-making event.

When it occurs, spatial distance becomes intimate distance. The environment should respond by becoming quieter, slower, warmer, more proximate, and more continuous.

A relationship in GEEHUB is therefore not only a graph edge. It can become a physically experienced condition of shared space.

The observer is not outside this event. The observer can be the one whose head is resting, the one receiving it, or the person witnessing the gesture. Those perspectives produce different worlds.

Core transformation:

RAW EVENT
→ CONTACT
→ TRUST / PERMISSION
→ SHARED DURATION
→ MEMORY
→ PLACE
→ STORY

The gesture is deliberately small. Its consequences are not.
