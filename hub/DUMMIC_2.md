# Dummic 2

Dummic 2 is the accumulating repository runtime inside GEEHUB.

The symmetrical directory is only the shell. Each man develops a characteristic repository from records, measurements, images, phrases, objects, places, noise, contradictions, and encounters. Records are preserved. Derived signatures organize rather than replace them.

Repositories operate on one another through typed operations: ECHO, OFFER, MUTATE, TRANSFER, CONTRADICT, AMPLIFY, and EMERGE. Every operation leaves provenance in both repositories and in the shared event log.

The runtime is local-first and currently uses browser localStorage so the world can accumulate between visits. RUN advances a day, injects noise, runs repository interactions, and periodically allows a new repository to emerge from existing material.

Core loop:

ACCUMULATE → CHARACTERIZE → CONTACT → ACT → ALTER → RECORD → ACCUMULATE

Dummic 2 does not decide what the material means in advance. Noise remains noise until recurrence or contact gives it another role.
