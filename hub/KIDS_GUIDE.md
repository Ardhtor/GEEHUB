# GEEHUB: super simple guide

1. Open `hub/index.html`.
2. You will see big boxes with project names.
3. Click a box to open it.
4. Use the big search box to find a project.
5. Click a tag to look for similar things.
6. You do not need to use a terminal for the web dashboard.

## What the buttons mean

**All** = show everything.

**Active** = things we are already working on.

**Incubating** = ideas that are growing into projects.

**Dormant** = ideas we can come back to later.

**Gods** = the myth/pantheon layer.

## Rule

If you don't know what to click, click the biggest interesting thing.

GEEHUB is supposed to help you find the next thing to make, not make you learn a filing system first.
