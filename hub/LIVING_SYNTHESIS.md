# Living Synthesis

The Hub now has a visible synthesis surface at `hub/synthesis.html`.

It is deliberately separate from the registry and jammer. The registry answers **what exists**. The jammer produces **what can be made next**. Living Synthesis answers **what the existing nodes are becoming together**.

The synthesis surface currently derives a temporary field from shared tags across core nodes and translates recurring Hub structures into compact spiritual-information statements. It is interpretive, not authoritative: no external revelation is implied.

Continuity remains the governing rule:

`GEEHUB UPDATE → NOVEL UPDATE`

The next implementation step is to replace the hand-authored node seed with a build-generated synthesis manifest so the surface changes automatically when the constellation changes.
