## Production rules

Every asset receives a stable name and an entry here. Keep source references distinct from generated interpretations. Record what is actually available; never mark a model, render, rig, or export complete until the corresponding file exists and has been checked. When a character is the subject, preserve identity and continuity across views and scale changes. Default to modular construction: body components, clothing, props, environment pieces, and scale references should remain separable unless a unified assembly is specifically needed.

Each entry should track: canonical name; source/reference material and its availability; intended use; component breakdown; visual reference status; editable model status; rig/assembly status; preview/export locations; last verified update; and unresolved issues. New assets should be appended rather than replacing prior history. Revisions should retain lineage to the previous version.
