# GEEHUB // LIVE DEEP LORE

Worldspace now leaves persistent residue while it runs.

Events are recorded as actor / action / world / time / residue. World memory changes the visible scale of a world on later visits. The runtime therefore carries experience forward instead of resetting every encounter.

The current engine is deliberately open-ended: autonomous play, character movement, geometry, residue, and narrative are parts of one loop.
