# DEEP LORE

Deep lore is a first-class reading of the corpus. It is not a decorative layer placed on top of an archive.

Its job is to preserve durable entities, motifs, mechanisms, places, transformations, relationships, continuities, and unresolved branches that emerge from the corpus.

Canon and experiments remain separate. Each lore object points back to the corpus material from which it emerged.

Working grammar:
mechanism → interface → transformation rule → continuity principle → setting → mythology

The raw archive remains authoritative for what a conversation actually contained. Lore is authoritative only for the state of the lore graph itself.
