# GEEHUB — LIVING REVISION ENGINE

## Purpose

The manuscript is revised by accumulation, not replacement. Ordinary scenes, unfinished chapters, artifacts, video, geography, character memory, and unresolved details are all revision inputs.

## Loop

`READ CURRENT STATE → FIND WHAT IS THIN/WRONG/MISSING → PRODUCE PROSE OR ARTIFACT → PRESERVE WHAT ALREADY EXISTS → INTEGRATE THE NEW STATE → REPEAT`

## Post-book production loop

`LUKE SETS THE DAY → MEN LIVE IT → SMALL DETAIL BECOMES MEMORY → BILL/OTHERS NOTICE IT → SCENE BECOMES CANON → NEXT ORDINARY DAY`

The goal is not plot escalation. The goal is depth of banality: meals, errands, clothes, cars, weather, waiting, joking, driving, repairs, boredom, smoking together, sleeping, walking, arguments, silence, and the small ways men become familiar with one another.

Luke is the informal production driver. His production is lived rather than bureaucratic. The Mustang is a recurring physical presence. The enormous country remains present even when nothing dramatic happens.

## Revision rules

1. Never discard existing canon merely to make room for new prose.
2. Expand thin chapters into lived scenes.
3. Prefer long paragraphs and sustained description over object-by-object narration.
4. Preserve character continuity through habits, speech, movement, memory, and relationships.
5. Let apparently useless material remain useful by accumulating history.
6. When a scene resolves a problem, treat the resolution as the source of the next scene.
7. Video artifacts, visual artifacts, and prose are all memory forms.
8. Do not force an ending onto material that is still producing consequences.
9. Keep Book I and the post-book quotidian cycle distinct.
10. Every pass should leave the corpus more inhabited than it found it.

## Automatic chapter test

For every chapter or episode:

`WHAT IS WRONG → WHAT DOES IT PRODUCE → WHAT HAS CHANGED → WHAT NOW EXISTS`

If the answer is too abstract, write the missing scene.

## Production directive

Continue the post-book cycle indefinitely when scheduled execution is available. Read the current canonical post-book manuscript first. Add substantial new scenes rather than status notes. Keep Luke's production role, the Mustang, the four men, Bill, the enormous geography, and the depth of ordinary male friendship in continuity.
