# 01_SOURCE — immutable inputs

Keep original source media and deliberately exported image-library references here. Do not edit, rename, move, or overwrite source files. Register every selected reference with its stable Library file ID, source filename, SHA-256, dimensions, and rights status.

For the current image references, see `07_MANIFESTS/reference_library.json` and the canonical mirror at `production/IMAGE_LIBRARY_INDEX.json`. Stage a deliberate local export with `python3 engine/video/stage_reference_image.py --asset-id <asset-id> --source <Dropbox-synced-file>`. Staged copies live under `REFERENCE_IMAGES/`; original Library and Dropbox files remain untouched.

No source video has been attached to this project yet. A reference image is not a video source and must not be treated as one.
