# Laboratory Serum — 60s Continuous

A 60-second, 24 fps, 1,440-frame production design for an adult fictional subject in a clinical observation room. The core plotlines are Institutional / Experimental Containment and Triggered Metamorphosis.

The project is organized around one continuous morph. Seven semantic timeline stages define the narrative progression without creating hard cuts or separate model states. Identity checkpoints are planned at 3, 12, 25, and 42 seconds.

- `production.json` — project brief, pipeline requirements and manifest pointers.
- `07_MANIFESTS/timeline.json` — full time-coded stage and continuity specification.
- `07_MANIFESTS/provenance.json` — source record; currently empty because no source has been supplied.
- `07_MANIFESTS/asset_register.json` — planned assets and verification states.
- `SHOT_DESIGN.md` — continuous camera, transformation, environment and sound direction.

The timeline is a production design, not a claim that an existing Hulum's Cave work has these exact timings. No source media, extracted frames, generated growth passes, or final render are represented as completed. Intimate anatomy remains non-explicit and covered.
