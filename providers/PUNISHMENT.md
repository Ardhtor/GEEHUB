# PUNISHMENT PROVIDER

Punishment is a GEEHUB provider: a source of consequence states that can be injected into videos, characters, rooms, encounters, and archival memories.

It does not define a single story. It provides a temporal grammar:

NOTICE → RESTRICTION → RECKONING → RELEASE

The provider can receive a rule, severity, and reflective question. It returns a state sequence that other engines can render.

Primary sensory operators:
- slower motion
- narrower space
- stronger contrast
- repeated gesture
- return to baseline

The result is stored as a thinking-memory transformation rather than a static label.
