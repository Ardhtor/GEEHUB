# GEEHUB narrative engine

This folder contains the construction chronicle: an in-world account of GEEHUB becoming a working video-generation environment.

- `CONSTRUCTION_CHRONICLE.md` is the continuous narrative.
- `STATE.md` is the evidence-based current construction state.
- `ENTRY_TEMPLATE.md` is the format for future entries.

The chronicle is a first-class project artifact. Update it when real work occurs; do not generate fictional progress. Keep prose atmospheric but precise, with the workshop, its tools, its artifacts, and its changing capabilities as the subject.
